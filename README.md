## About Me

I'm an aspiring **AI Systems Engineer** focused on building secure, reliable, and intelligent software systems. I enjoy working at the intersection of AI, backend engineering, and systems programming to turn complex ideas into practical, production-oriented solutions.

My engineering interests include:

- **AI-native systems** — building software that can reason, use tools, and execute workflows.
- **Systems engineering** — exploring networking, concurrency, performance, and low-level computing.
- **Backend infrastructure** — designing APIs, services, and scalable application architectures.
- **Secure software** — writing maintainable, dependable systems with security in mind.

I value strong engineering fundamentals, thoughtful architecture, and learning by building real projects.
