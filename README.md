### About

Computer Science student at UET Lahore, building products end-to-end — schema design through deployment. My recent focus is on AI agent architecture: systems where a model proposes an action and a validated backend function executes it, never a system that trusts the model to act freely. I'd rather ship something small that actually works under real constraints than a large demo that only works on the happy path.

**[RelayOS](https://github.com/MuhammadBilal561/RelayOS)** — An AI front-office platform for service businesses. Answers customer questions grounded only in a real knowledge base, books real calendar appointments through explicit server-validated functions, and reports "revenue recovered" instead of vanity metrics.
